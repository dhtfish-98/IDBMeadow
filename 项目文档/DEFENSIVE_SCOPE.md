# IDBMeadow 防御用途与本轮复核范围

复核日期：2026-10-04。

## 实际防御用途

离线读取有权限持有的 IDB/I64，调查结构、类型、函数和其他分析元数据。

## 实际能力

解析库读取数据库，offline_tools 可导出数据；run_ida_script 会执行调用者指定的 Python 文件并安装本进程 IDAPython 接口，不是脚本沙箱。dump_scripts 可导出数据库保存的脚本，dump_user 可显示用户/许可证元数据。

## 当前检查

本轮核对数据库读取、script_environment 和 offline_tools 的执行/导出路径；保留 Apache-2.0 来源及 fixture 归属。1.0.2 实质重写本地稳定输入、头/分段、flag/name 页与 TIL 解压和记录入口；47 份原始数据库的观察保持一致。既有及本轮验证的版本、XFAIL 和耗时边界见 VALIDATION.md。

## 验证边界

只运行自己审核且获准运行的脚本；申请材料避免披露数据库内的个人或许可证信息。IDA 8/9 和所有畸形数据库未证明；1.0.2 完整慢速套件的结果原样保存在 `历史/1.0.2/CURRENT_VALIDATION.json`，1.0.3 验证记录原样保存在 `历史/1.0.3/CURRENT_VALIDATION.json`，1.0.4 的本地执行范围记录在 CURRENT_VALIDATION.json。本次仅修复测试断言与一处针对既有 7.6/x32 夹具的旧预期；运行时源码未改，不扩大所支持的 IDA 版本范围。

## 1.0.2 有界解析的确切范围

每次数据库读取先取得有限的不可变字节，检查实际分段范围和重叠，再处理
完整压缩成员。每段/类型桶解压有独立上限，所有分段及三个类型桶共用累计
物化字节与类型记录计数。flag/name 页按实际字节建立视图，不依据输入声明
分配巨量零字节；类型记录逐字段核对终止符和跨度。名称页的老格式声明保留，
实际缓冲区仅覆盖存在的字节。所有正常数据库观察及独立手工记录见验证说明。

这不是全部项目重写完成：B-tree、语义对象、类型语言、IDA 接口与脚本/导出
流程仍有继承实现，缺少通用 CPU/递归/缓存/输出预算；真实设备和 IDA 8/9 未验证。
底层调用者指定 Python 脚本的能力继续按实际用途声明。
